# Wall 頁面設計參考示意圖

這個資料夾包含 Wall 頁面的設計參考示意圖，用於指導 Phase 0-1 的實作。

## 檔案說明

- `wall-page-reference-1.png` - Wall 頁面整體佈局參考（包含每日主題、發文區、feed）
- `wall-page-reference-2.png` - Wall 頁面詳細 UI 元素參考（貼文卡片、導航欄）

## 設計要點

根據示意圖，Wall 頁面應具備以下視覺特徵：

1. **像素風格 UI**
   - 粗邊框（`border-3`）
   - 像素風格陰影（`shadow-[4px_4px_0_rgba(0,0,0,0.25)]`）
   - 網格背景
   - 無圓角設計

2. **Threads 風格 Feed**
   - 垂直排列的貼文卡片
   - 每張卡片包含：頭像、名稱、時間、內容、圖片
   - 卡片間有適當間距

3. **發文輸入區**
   - 文字輸入框（多行）
   - 圖片上傳按鈕
   - 圖片預覽功能
   - 發佈按鈕

4. **底部導航欄**
   - W 按鈕位於 D、M、P 之後，Logout 之前
