### 【05:00-05:50】技術架構介紹

**畫面：** 顯示技術架構圖或程式碼結構

**旁白：**
> 接下來介紹技術架構。
> 
> **前端**：使用 Next.js 14 App Router 搭配 TypeScript，樣式使用 Tailwind CSS 並客製 Pixel 風格主題，狀態管理使用 Zustand。
> 
> **後端**：使用 Next.js API Routes 作為後端，資料庫使用 Prisma ORM 搭配 PostgreSQL。
> 
> **即時通訊**：使用 Pusher 實現即時推送，並有 5 秒輪詢作為 fallback 機制。
> 
> **其他服務**：認證使用 JWT 和 Google OAuth 2.0，檔案儲存使用 Vercel Blob Storage，AI 服務使用 Google Gemini API 生成每日主題和 AI Coach 建議。
> 
> **部署**：部署在 Vercel，支援自動部署和環境變數管理。

## 【技術架構詳細說明】

### 前端技術棧
- **Next.js 14 (App Router)**：現代化的 React 框架，支援 SSR 和 API Routes
- **TypeScript**：型別安全，提升開發體驗
- **Tailwind CSS**：快速開發，客製 Pixel 風格主題
- **Zustand**：輕量級狀態管理，支援 localStorage 持久化

### 後端技術棧
- **Next.js API Routes**：全端框架，前後端統一技術棧
- **Prisma ORM**：型別安全的資料庫查詢
- **PostgreSQL**：關聯式資料庫，穩定可靠

### 第三方服務
- **Pusher**：即時通訊服務，WebSocket 推送
- **Google OAuth 2.0**：第三方登入
- **Vercel Blob Storage**：檔案儲存服務
- **Google Gemini API**：AI 服務，生成每日主題和開場白
- **Nodemailer**：郵件發送服務

### 部署與 DevOps
- **Vercel**：自動部署，環境變數管理
- **GitHub**：版本控制
- **Prisma Migrate**：資料庫遷移管理
