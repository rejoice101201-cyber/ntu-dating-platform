## 對話流程狀態機（更新）

```
idle 
  ↓
greeting (歡迎訊息 + 功能選單)
  ↓
menu_selection
  ├─ clinic_info → (地址/交通腳本) → end
  ├─ service_info → (服務項目腳本) → end
  ├─ appointment_reminder → (預約提醒腳本) → confirm_attendance → end
  ├─ appointment_policy → (報到提醒腳本) → end
  ├─ cancellation_policy → (取消政策腳本) → end
  ├─ post_treatment_care → (術後照顧腳本) → end
  ├─ faq → (腳本匹配) → end
  ├─ symptom_consultation → (LLM) → end
  └─ human_transfer → end
```

## 服務層架構（更新）

```
services/
  ├── lineService.ts           # Line API 封裝（發送訊息、Reply Templates）
  ├── llmService.ts            # Gemini API 封裝（含速率限制、錯誤處理）
  ├── scriptService.ts         # 腳本匹配引擎（關鍵字匹配、預設回應）
  ├── conversationService.ts   # 對話流程管理（狀態機、歷史記錄）
  ├── rateLimitService.ts      # 速率限制管理（請求追蹤、降級策略）
  └── messageTemplateService.ts # 訊息模板服務（格式化腳本回應）
```
