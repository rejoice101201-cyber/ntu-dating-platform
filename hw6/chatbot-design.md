# 木木日安醫學美容診所 Line Bot 對話/功能設計

## 1. 專案概述

### 1.1 專案名稱
木木日安醫學美容診所 Line Bot（復興館）

### 1.2 專案目的
為木木日安醫學美容診所（復興館）提供智能客服服務，協助使用者：
- 查詢診所資訊（地址、電話、營業時間、交通方式）
- 了解服務項目
- 預約相關諮詢
- 症狀初步諮詢
- 術後照顧指導
- 其他常見問題解答

### 1.3 主要功能概述
- **Rich Menu 快捷功能**：8 個快捷按鈕，提供常用功能快速存取
- **關鍵字智能匹配**：自動識別使用者意圖，提供對應的腳本回應
- **AI 對話功能**：整合 Google Gemini API，處理複雜問題
- **多語系支援**：支援繁體中文與英文
- **多媒體訊息支援**：支援文字、圖片、影片、音訊、位置、貼圖等訊息類型
- **對話記錄儲存**：所有對話記錄持久化至資料庫

## 2. 對話流程設計

### 2.1 初始對話流程

#### 使用者加入 Bot（Follow/Join 事件）
1. 使用者透過 LINE 搜尋或掃描 QR Code 加入 Bot
2. Bot 自動發送歡迎訊息（Buttons Template）
3. 歡迎訊息包含：
   - 標題：「👋 歡迎來到木木日安醫學美容！」
   - 內容：介紹 Bot 功能與服務範圍
   - 4 個快捷按鈕：
     - 📍 診所資訊
     - 💆 服務項目
     - 📅 預約相關
     - ❓ 其他問題
   - Quick Reply 選項（快速回覆按鈕）

#### 對話狀態管理
- **idle**：初始狀態
- **greeting**：歡迎訊息已發送
- **menu_selection**：使用者正在選擇功能
- **clinic_info**：查詢診所資訊
- **service_info**：查詢服務項目
- **appointment**：預約相關
- **symptom_consultation**：症狀諮詢（使用 LLM）
- **ended**：對話結束

### 2.2 文字訊息處理流程

```
使用者輸入文字訊息
    ↓
關鍵字匹配（sectionMatcher）
    ↓
是否匹配到章節？
    ├─ 是 → 發送對應的腳本回應
    │        ├─ 一般章節：文字訊息
    │        ├─ schedule：文字訊息 + Carousel Template
    │        └─ products：Flex Message Carousel
    │
    └─ 否 → 使用 LLM 處理
             ├─ 成功 → 發送 AI 回應
             └─ 失敗 → 發送降級回覆
```

### 2.3 Postback 事件處理流程

當使用者點擊 Rich Menu 按鈕或 Template 中的按鈕時：
1. 解析 Postback Data（`action=xxx&type=xxx`）
2. 根據 action 類型執行對應處理：
   - `action=appointment`：處理預約相關
   - `action=refer_friend`：處理推薦好友
   - `action=edit_profile`：處理修改資料
   - `action=products`：處理嚴選產品
3. 發送對應的回應訊息
4. 儲存對話記錄

### 2.4 其他訊息類型處理

- **圖片訊息**：回覆提示訊息，建議使用者描述圖片內容
- **影片訊息**：回覆提示訊息，建議使用者描述問題
- **音訊訊息**：回覆提示訊息，建議使用者使用文字描述
- **位置訊息**：回覆診所地址與交通資訊
- **貼圖訊息**：回覆友善的問候訊息

3. 未匹配則使用 LLM 處理

## 5. LLM 整合設計

  1. gemini-2.0-flash-exp（主要使用）

  4. gemini-1.5-flash（備用）
  5. gemini-1.5-pro（備用）

### 5.2 System Prompt 設計原則

#### 5.2.1 重要原則
1. **不能提供醫療診斷或治療建議**
2. **遇到具體症狀，必須建議預約看診**（電話：02-2778-7178）
3. **語氣友善、專業、有同理心**
4. **回答簡潔明確**（最多 200 字）
5. **適時引導使用者使用選單功能或致電診所**

#### 5.2.2 診所資訊（包含在 System Prompt 中）
- 名稱：木木日安醫學美容（復興館）
- 地址：台北市大安區復興南路一段81號
- 電話：02-2778-7178
- 營業時間：週一至週五 09:00-18:00，週六 09:00-12:00（週日休診）
- 交通：捷運忠孝復興站5號出口，步行3分鐘

#### 5.2.3 服務項目（包含在 System Prompt 中）
- 染料雷射（建議1個月進行一次，需多次治療）
- 光纖亮透淨雷射
- 果酸保養／果酸換膚
- 一般皮膚科診療
- 青春痘治療
- 皮膚過敏診斷
- 皮膚保養諮詢

#### 5.2.4 重要政策（包含在 System Prompt 中）
- 付款方式：僅限現金（尚無提供刷卡、匯款服務）
- 報到延遲超過10分鐘以上，可能會取消當日治療
- 臨時取消或當日治療未到診兩次，會取消線上預約資格
- 館內為維護隱私與靜謐，接待空間僅限接待治療者本人

#### 5.2.5 回應風格
- 使用繁體中文（或英文，根據使用者語系）
- 語氣親切但不失專業
- 適時使用表情符號（🔔📌♦等，但不過度）
- 結尾可提供下一步建議（如：如需預約請致電 02-2778-7178）

### 5.3 對話歷史管理
- **保留輪數**：最近 3 輪對話
- **格式**：`角色: 內容`（使用者/助手）
- **用途**：提供上下文給 LLM，使回應更連貫

### 5.4 降級處理機制

當 LLM 處理失敗時：
1. **第一層降級**：發送友善的降級回覆
   - 說明目前無法提供 AI 回應
   - 提供可協助的項目（診所資訊、服務項目、預約等）
   - 建議致電診所：02-2778-7178

2. **第二層降級**：如果發送降級回覆也失敗
   - 記錄錯誤日誌
   - 不中斷對話流程

- **不提供醫療診斷**：Bot 僅提供資訊查詢與初步諮詢，不提供醫療診斷或治療建議
